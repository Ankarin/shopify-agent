# shopify-agent

Shopify AI agent — Next.js + AI SDK + Drizzle + Supabase + Clerk; embeddable storefront chat.

**Live:** https://shopify-agent-ashen.vercel.app

## Stack

- TypeScript
- Next.js
- React
- Drizzle ORM
- Supabase
- Clerk auth
- Tailwind
- shadcn/ui
- Vercel AI SDK

## Run

```bash
bun install
bun run dev
```
